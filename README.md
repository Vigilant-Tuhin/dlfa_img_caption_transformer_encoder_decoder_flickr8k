# dlfa_img_caption_transformer_encoder_decoder_flickr8k
Flickr8K Image Captioning | Custom Transformer vs Native PyTorch vs ViT-GPT2
Deep learning assignment comparing three image captioning architectures on Flickr8K. 
Implements a patch-based Transformer encoder-decoder from scratch, replicates it using PyTorch's built-in Transformer layers, and benchmarks both against HuggingFace's pre-trained ViT-GPT2. Covers sinusoidal positional encoding, causal masking, teacher forcing, beam search decoding, and multi-reference BLEU evaluation.
